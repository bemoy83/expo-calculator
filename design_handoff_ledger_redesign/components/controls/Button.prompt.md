Button with six variants: accent for page-primary, primary (ink) for commits, secondary, ghost, danger, inverse (inside CommitBlock).

```jsx
<Button variant="accent">+ New calculator</Button>
<Button variant="secondary">Edit</Button>
<Button variant="primary" block>Save material</Button>
```

**Repo target:** components/ui/Button.tsx. Port to Tailwind using the recipes in MIGRATION.md; keep every value.
